# Fap Kolo Support

Welcome to the Fap Kolo support page.

If you need help with Fap Kolo, including gameplay, purchases, restoring purchases, or technical issues, please contact us using the support information below.

## In-App Purchases

Fap Kolo offers optional cosmetic upgrades through Apple's In-App Purchase system.

If you previously purchased an upgrade and it is not available, use the **Restore Purchases** option in Fap Kolo.

## Troubleshooting

If you experience an issue with the game, please include the following information when contacting support:

* Your device model
* Your iOS version
* A description of the problem
* Any steps that reproduce the issue

Please do not send passwords, payment card information, or other sensitive information.
